VIDEO DISCERNMENT

Before treating one video as “the truth”

Locate the speaker

Watch contrasts

Separate role from workplace

Verify the route

Licensing, admission rules and course structures can change.

SETTINGS & PRIVACY

Keep the atlas under your control.

This static GitHub Pages build does not send your notes to a backend. Data remains in this browser unless you export it.

SEARCH-ENGINE SHIELD

Already switched on

Every HTML page contains noindex, nofollow, noarchive and nosnippet directives. A 404 page carries the same directives. No sitemap is generated.

This reduces search visibility; it does not make a public GitHub Pages URL private or secret.
